## Kept as is (audited, no change needed)
- Scroll architecture (native scroll → damped path, dwell, warp/ground-crossing veils) — the previous phase's transition sweep and this phase's 10-cycle soak show no desynchronisation.
- Typography reveals — headings already use masked line reveals, eyebrows/descriptions blur-to-sharp, grids staggered cascades; adding more motion would hurt usability.
- Content architecture, gate and assistant boundaries (content freeze).
- Accessibility structure (axe-clean); reduced motion and no-WebGL fallbacks.

## Found during implementation (and fixed)
- **Sky seam** (introduced by an early iteration of this phase): a teal "fringe" term on low fbm values exposed a value-noise lattice seam as a hard-edged dark disc at the universe station. Isolated by live shader bisection; term removed; `pow()` on a possibly negative base replaced by `x*x`.
- `LatheGeometry` leaves one profile normal unnormalised on 2-point strips — normals now normalised in the ring builder (matters for tangent generation).
