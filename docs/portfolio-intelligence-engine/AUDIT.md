## Content and gates

- 15 JSON files validated by zod in `src/content/index.ts`; every record carries `verification.status` ∈ `placeholder | owner_verified | public_verified`. `npm run content:gate` reported **40 pending** records.
- Verified and public: site identity (name, role, proposition, hero/identity statements), home section copy, LinkedIn, GitHub, email, résumé PDF availability, portrait, intro reel (the reel's transcript and AI disclosure are `placeholder`).
- Placeholders: all 4 projects, 4 case studies, 4 capability groups, 8 journey entries, 5 principles, 3 identity pillars, the 10 demo assistant entries.
- `src/content/data/verified-links.json`: owner-verified but **unrendered** registry from the temporary CV (phone `publicDisplay: false`, 6 repositories, 9 certificates).
- Consequence: the approved corpus is small; projects/skills/experience can only be answered honestly as "pending" with links (spec §5 "ship honest partial answers").

## 3D / WebGL

- One persistent R3F canvas (`ExperienceCanvas.tsx`), quality tiers + runtime governor (`PerformanceGovernor` downgrades on sustained low FPS, ignores frame gaps > 250 ms), static tier for no-WebGL/low-end, context-loss guard.
- Existing pause API: zustand `mediaOverlay` → `frameloop={reduced || covered ? 'demand' : 'always'}` (the reel player sets it); on-demand frames still render on scroll (`Orchestrator` invalidates on scroll). **Reused** for Local AI (`aiRenderHold`).
- Known risks carried in: desktop cold shader-compile stalls on first frames; mobile LCP above budget (release-readiness: 3.1 s home in the last measurement).

## Security baseline

CSP `default-src 'self'; script-src 'self' 'unsafe-inline'; … connect-src 'self'; worker-src 'self' blob:; frame-ancestors 'none'; object-src 'none'` + `X-Frame-Options: DENY`. No third-party origin. Local AI needs `'wasm-unsafe-eval'` and the model hosts in `connect-src` (implemented, see SECURITY-AND-PRIVACY.md).

## Performance baseline method

The baseline is commit `e33860b`, built from `git archive` into the git-ignored `.evidence-tmp/baseline-app` (Turbopack does not follow a junctioned `node_modules`; without its own lockfile the app resolves the repository's `node_modules`) and served next to the feature build. Measurements are interleaved A/B on the same machine with the owner's Chrome idle (checked per process: 0 CPU s over 3 s). Results: [GPU-AND-PERFORMANCE.md](./GPU-AND-PERFORMANCE.md).
